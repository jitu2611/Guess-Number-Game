# Guess Number Game

A Bull-and-Cows number-guessing game implementation.

> **Archived learning project.** The original source is distributed in `Guess.zip` and retained as an early programming exercise.

## Game concept

A player guesses a secret number. Each attempt receives feedback:

- **Bull**: a correct digit in the correct position
- **Cow**: a correct digit in a different position

```text
Secret number + player guess → compare digits and positions → bulls/cows feedback → next guess
```

## Running

Extract `Guess.zip`, then follow the project-specific instructions contained in that archive.

## Scope

This repository is preserved for its game-logic exercise rather than active development.
